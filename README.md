# Yumi OPIc — 오픽 모의고사 셔플

서베이 주제 · 돌발 · 롤플레이 · 고난도 문항을 **실제 OPIc 콤보 구조 그대로** 섞어
매번 새로운 15문항 시험지를 만들어 주는 연습 도구입니다.
문제는 텍스트로 보고, 답변은 타이핑(또는 마이크)으로 작성한 뒤 한자리에 모아 다시 읽어볼 수 있습니다.

## 시험지 구조

| 문항 | 유형 | 묶음 |
|---|---|---|
| 1 | 자기소개 | 기본 스킵 (옵션으로 켤 수 있음) |
| 2 / 3 / 4 | 묘사 → 활동 루틴 → 과거 경험 | 콤보 1 · 서베이 주제 A |
| 5 / 6 / 7 | 묘사 → 과거 경험 → 가장 기억에 남는 경험 | 콤보 2 · 서베이 주제 B |
| 8 / 9 / 10 | 묘사 → 과거 경험 → 가장 기억에 남는 경험 | 콤보 3 · 돌발 주제 |
| 11 / 12 / 13 | 질문하기 → 문제 해결 → 관련 경험 | 콤보 4 · 롤플레이 |
| 14 / 15 | 이슈 · 변화 → 비교 · 전망 | 콤보 5 · 고난도 |

콤보 1과 콤보 2는 항상 **서로 다른** 서베이 주제에서 뽑히고, 같은 주제 안에서
같은 문제가 두 번 나오지 않도록 막아 둡니다.

## 문제 은행

전체 **75주제 540문항**. 문항마다 출처를 표시합니다.

| 표시 | 뜻 |
|---|---|
| **기출 복원** (108문항, 20%) | 응시자들이 복원해 공개한 실제 출제 문항을 그대로 옮긴 것. 원문의 오타·비문도 손대지 않았습니다 |
| **형식 기반** (432문항, 80%) | 기출이 아니라 OPIc 형식·유형을 따라 만든 연습 문항 |

> OPIc 공식 문제은행은 ACTFL/크레듀가 공개하지 않습니다. 시중 교재의 "기출"도
> 모두 응시 후기를 모은 복원본이며, 여기 실린 "기출 복원"도 마찬가지라 실제
> 시험 문구와 다를 수 있습니다.

- **서베이 11주제 143문항** (기출 복원 32) — 혼자 아파트 거주 / 음악 듣기 /
  해변 / 공원 / 콘서트 / 쇼핑 / 조깅 / 걷기 / 헬스 / 집에서 보내는 휴가 /
  해외여행. 모두 실제 배경 서베이 항목입니다.
- **돌발 32주제 215문항** (기출 복원 50) — 날씨 · 은행 · 식당 · 교통 · 인터넷 ·
  재활용 · 명절 · 호텔 · 약속 · 건강 · 동네 · 여가 · 가구가전 · 도서관 · 카페 ·
  영화 · TV드라마 · 독서 · 요리 · 국내여행 · 지형지리 · 산업 · 프로젝트 ·
  전화통화 · 패션 · 미용실 · 가족친구 · 모임파티 · 직장 · 학교 · 캠핑 · 술집
- **롤플레이 16세트 106문항** (기출 복원 14)
- **고난도 16세트 76문항** (기출 복원 12)

## 문항 출처

"기출 복원" 문항은 아래 공개 자료에서 옮겼습니다.

- [오픽만수르 모의고사 1·2·3·4·7·8회](https://opicmansur.com/category/script/%EB%AA%A8%EC%9D%98%EA%B3%A0%EC%82%AC/) — 집·카페·가구·공원·걷기·은행·술집·날씨·재활용·지형·약속·명절·기술·캠핑·패션·쇼핑 및 롤플레이·고난도
- [wxxk's dev log — 음악 유형 10개 기출문제 / 모의고사](https://jaewxxkshin.github.io/opic/opic-4/) — 음악·영화 10유형, 지형·공원·걷기 콤보
- [Joseph's YHC English Class — OPIc](https://josephenglishyhc.wordpress.com/category/opic/) — 조깅·영화·여행 문항
- [오픽 서베이 항목 2026 정리 — 링커리어](https://community.linkareer.com/employment_data/6059579) — 배경 서베이 항목 대조
- [OPIc — 나무위키](https://namu.wiki/w/OPIc) — 시험 구성·돌발 주제 범위 확인

주제는 `src/data/` 아래 네 개 파일로 나뉘어 있습니다. 문항을 추가하려면 해당
파일의 `questions` 배열에 `{ id, type, en, ko, hints }` 를 넣기만 하면 됩니다.

## 모드

- **실전 모의고사** — 2~15번 14문항을 콤보 구조대로 한 세트 생성
- **주제별 연습** — 주제 하나를 골라 그 주제의 문항만 5개 셔플
- **랜덤 1문제** — 전체 은행에서 아무 문제나 하나

## 자동 채점은 없습니다

예전에는 단어 수·연결어·표현 사전 매칭으로 100점 만점 점수와 추정 등급(NH~AL)을
매겼지만, 실제 OPIc은 발음·유창성·상호작용까지 사람이 듣고 평가하는 시험이라
텍스트만 보고 매긴 점수는 실제 등급과 맞지 않았습니다. 잘못된 숫자가 오히려
감을 흐려서 걷어냈습니다.

대신 결과 화면에서는 문항별 답변 원문과 **단어 수 · 소요 시간**만 그대로
보여줍니다. 연습 중 표시되는 유형별 목표 단어 수와 목표 시간도 점수가 아니라
"이 정도 분량은 말해 보자"는 기준선입니다.

## 음성 기능 (무료)

유료 음성 API를 쓰지 않고 브라우저 내장 Web Speech API만 사용합니다.

- **문제 읽어주기** — `speechSynthesis`, 대부분의 브라우저에서 동작
- **마이크 받아쓰기** — `SpeechRecognition`, Chrome · Edge에서 동작

둘 다 선택 사항이라 타이핑만으로도 연습할 수 있습니다.

## 로컬 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Node 20 이상이 필요합니다.

## Vercel 배포

백엔드가 없고 모든 상태를 브라우저 `localStorage`에 저장하므로 별도 환경 변수
설정 없이 그대로 배포됩니다.

1. 이 저장소를 GitHub에 올립니다.
2. [vercel.com/new](https://vercel.com/new) 에서 저장소를 임포트합니다.
3. Framework Preset이 **Next.js** 로 잡히는지만 확인하고 Deploy를 누릅니다.
   (Build Command · Output Directory 모두 기본값 그대로 두면 됩니다.)

CLI로 배포하려면:

```bash
npx vercel        # 미리보기 배포
npx vercel --prod # 프로덕션 배포
```
